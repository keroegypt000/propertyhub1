# 🏢 PropertyHub — نظام إدارة العقارات

نظام متكامل وآمن لإدارة المباني والوحدات والمستأجرين والعقود، مبني بـ **Next.js 16 + Prisma + SQLite** مع واجهة عربية كاملة (RTL).

## ✨ المميزات

| القسم | الوصف |
|-------|-------|
| 🏠 لوحة التحكم | إحصائيات فورية: الإيجارات الشهرية، المدفوعات المتأخرة، الصيانة المفتوحة |
| 🏢 المباني | إضافة وتعديل وحذف المباني مع دعم مدن الكويت |
| 🚪 الوحدات | شقق، مكاتب، محلات، مستودعات — مع تتبع الحالة والإيجار |
| 👥 المستأجرين | بيانات كاملة + ضامن + رفع البطاقة المدنية والمستندات |
| 📄 العقود | عقود إيجار بتاريخ بداية/نهاية وتأمين ويوم دفع |
| 💰 المدفوعات | تسجيل الدفعات وحالتها (مدفوع / معلق / متأخر) |
| 🔧 الصيانة | طلبات صيانة بأولويات + رفع صور المشكلة |
| 📊 الإيرادات والمصروفات | حركات مالية مربوطة بالمباني |
| 🏦 القروض | قروض وأقساط مع حساب المتبقي تلقائيًا |
| 📒 الحسابات | شجرة حسابات كاملة + قيود يومية (مدين/دائن) |
| 📁 الملفات | رفع صور ومستندات PDF مع معاينة مصغرة داخل كل سجل |
| 🛡️ نقاط الاستعادة | نسخ احتياطية تلقائية بعد كل عملية + استعادة بنقرة |
| 🔍 سجل التدقيق | تتبع كل إجراء: من فعل ماذا ومتى |
| 👤 المستخدمين | أدوار متعددة مع صلاحيات دقيقة لكل قسم |

## 🔐 الأدوار والصلاحيات

| الدور | الصلاحيات |
|------|-----------|
| **مدير (admin)** | كل شيء |
| **مدير فرعي (manager)** | كل شيء ما عدا إدارة المستخدمين الكاملة |
| **محاسب (accountant)** | العقود، المدفوعات، الحركات المالية، القروض، الحسابات، القيود |
| **محصّل (collector)** | تسجيل المدفوعات والصيانة فقط |
| **مشاهد (viewer)** | قراءة فقط |

## 🚀 التشغيل محليًا

```bash
# 1. تثبيت الحزم
npm install

# 2. إعداد قاعدة البيانات
npx prisma db push
npx prisma generate

# 3. إنشاء ملف .env
echo 'DATABASE_URL="file:./dev.db"' > .env

# 4. تشغيل السيرفر
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

### الحساب الافتراضي (أول مرة)

عند أول تشغيل ستظهر شاشة الإعداد لإنشاء حساب المدير.
الحساب التجريبي: `admin` / `admin123`

## ☁️ النشر على Vercel

المشروع جاهز للنشر على Vercel مع دعم `output: standalone`:

1. ارفع المشروع على GitHub
2. اربط المستودع في [vercel.com](https://vercel.com)
3. أضف متغير البيئة `DATABASE_URL` (استخدم Turso أو أي SQLite مستضاف)

## 🛠️ التقنيات

- **Next.js 16** (App Router) + **React 19**
- **TypeScript**
- **Tailwind CSS 4** + **shadcn/ui**
- **Prisma ORM** + **SQLite**
- **Lucide Icons** + **Sonner** للتنبيهات
- مصادقة مزدوجة: Cookies (HttpOnly) + Bearer Token
- تشفير كلمات السر بـ scrypt
